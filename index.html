What it does

Four tabs, one window, zero setup.

Tweaks

Privacy & telemetry, performance, interface — 18 tweaks, every one backed up and reversible individually.

Install

31 popular apps via winget. Shows what's already installed and skips it automatically.

Debloat

41 bloat targets: Cortana, Copilot app, new Outlook, Teams consumer, Solitaire pack, and Windows' "suggested apps" re-installer — with a dry-run preview.

Windows Update

Security-only (patches now, feature updates deferred a year), restore defaults, force a check — always reversible.

It won't break your PC. Every registry change is backed up before it's applied, every tweak has built-in revert values, debloat never touches Store, Defender or Windows Update, and there's a full dry-run mode: preview everything, change nothing.

For the terminal people

Everything the GUI does, scriptable. Requires the file version — grab peak.ps1 from GitHub.

PS>.\peak.ps1 -Install vscode,git,7zip -Tweaks privacy,ui -Updates security -Debloat
  • .\peak.ps1 -List — the full catalog: every tweak, app and feature
  • .\peak.ps1 -UndoTweaks ui — revert exactly what you changed
  • .\peak.ps1 -Everything -DryRun — preview everything, touch nothing
  • .\peak.ps1 -RestoreBackup <timestamp> — re-import a registry backup
